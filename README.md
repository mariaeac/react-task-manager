Este projeto foi desenvolvido como parte de um curso introdutório de React. Ele demonstra os conceitos básicos de criação de componentes, gerenciamento de estado e consumo de APIs, utilizando a [API do JSON Placeholder](https://jsonplaceholder.typicode.com/).


## 📌 Funcionalidades

- **Adicionar Task e Descrição:** Criação de novas tarefas com uma breve descrição.
- **Deletar Task:** Remoção de tarefas já existentes.
- **Integração com JSON Placeholder:** Consumo de uma API REST.
